# Directory contents

Lists immediate project-controlled children and their purpose; use this index to select relevant files.

- [AUTHORIZATION.md](AUTHORIZATION.md) — Records the effective human operating grant and links to original grants, amendments and restrictions; this view creates no new permission.
- [AUTONOMY.md](AUTONOMY.md) — Defines the development loop, cumulative limits, stopping boundaries and completion gates under actual human authority.
- [backend_changes/](backend_changes/FOLDER_CONTENT.md) — Project-controlled backend changes directory.
- [BACKEND_MAINTENANCE.md](BACKEND_MAINTENANCE.md) — Defines the narrow backend-maintenance exception and its evidence requirements; dated additional authority remains limited to its original task.
- [backend_patches/](backend_patches/FOLDER_CONTENT.md) — Project-controlled backend patches directory.
- [benchmarks/](benchmarks/FOLDER_CONTENT.md) — Project-controlled benchmarks directory.
- [BOOTSTRAP.md](BOOTSTRAP.md) — Documents the one-time meaningful validation bootstrap for a Markdown-only source; it does not apply to the existing implemented product.
- [CODEX_START.md](CODEX_START.md) — Provides a concise restart prompt for this commissioned repository; it grants no authority and does not automatically resume a stopped session.
- [CODEX_START_AUTONOMOUS.md](CODEX_START_AUTONOMOUS.md) — Provides an optional initial-commissioning template; it is not a current grant or an instruction to recommission this repository.
- [decisions/](decisions/FOLDER_CONTENT.md) — Project-controlled decisions directory.
- [ENVIRONMENT.md](ENVIRONMENT.md) — Defines non-secret operating requirements for permitted future CWI work; dated readiness observations belong to their runs and historical records.
- [FOLDER_CONTENT.md](FOLDER_CONTENT.md) — Immediate-child navigation index.
- [history/](history/FOLDER_CONTENT.md) — Project-controlled history directory.
- [MODEL_POLICY.md](MODEL_POLICY.md) — Defines approved development-role selections, reasoning limits, fresh-access verification and immutable historical settings.
- [phases/](phases/FOLDER_CONTENT.md) — Project-controlled phases directory.
- [PIPELINE_REVIEW.md](PIPELINE_REVIEW.md) — Preserves the supplied-backend assessment and its limitations; it is historical inspection evidence rather than current product acceptance.
- [README.md](README.md) — Explains the separation between current coordination, detailed evidence and historical records so sessions can read selectively.
- [requests/](requests/FOLDER_CONTENT.md) — Project-controlled requests directory.
- [REQUIREMENTS.md](REQUIREMENTS.md) — Preserves every mandatory requirement and its stable ownership/acceptance rules; links to execution evidence instead of accumulating checkpoint narratives.
- [review/](review/FOLDER_CONTENT.md) — Project-controlled review directory.
- [RUNBOOK.md](RUNBOOK.md) — Provides setup and operational commands for authorized CWI work, including current role-specific flags and exact integration controls.
- [runs/](runs/FOLDER_CONTENT.md) — Project-controlled runs directory.
- [templates/](templates/FOLDER_CONTENT.md) — Project-controlled templates directory.
- [UPDATE_GUIDE.md](UPDATE_GUIDE.md) — Explains which development records to update, when and how, without losing authority, evidence, budgets or unfinished-run recoverability.
