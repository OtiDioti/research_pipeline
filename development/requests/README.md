# Coding-pipeline requests

Each request is a bounded, committed implementation assignment. Use [the template](../templates/REQUEST.md). The original specification stays authoritative, but the request gives CWI an actionable scope and measurable acceptance criteria without relying on a stale outer conversation.

- [REQ-D01-001](REQ-D01-001.md): first testable product foundation; proposed until D00 confirms it.

Before launch, commit the exact request with its referenced materials and validation policy. CWI snapshots supplied request/context inputs. Editing a source file after start does not change the frozen assignment. Use a new request/run to change scope after safely resolving the earlier run. Do not attempt to replace the frozen input in retained controller state.
