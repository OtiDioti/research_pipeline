# Frozen implementation requests

Explains how to locate committed CWI requests and preserve their original contents and authority boundaries.

[FOLDER_CONTENT](FOLDER_CONTENT.md) describes each request. Use [the request template](../templates/REQUEST.md) for a newly authorized scope, then commit its exact launch input before CWI.

Launched request bodies remain byte-for-byte unchanged, including historical headings or readiness statements. Their purpose is described by their titles and this index rather than by adding prose to hashed inputs. Current authority, execution and integration come from AUTHORIZATION, STATUS and owning run evidence; a frozen READY label is not current launch permission.

Original request/index contents remain in the [preservation manifest](../history/MANIFEST.md). This migration does not start or amend an implementation request.
