# Individual development decisions

Explains how to find decision rationale without loading the complete historical decision ledger.

[DECISIONS](../../DECISIONS.md) indexes all93 prior DEV definitions and DEV-094; [FOLDER_CONTENT](FOLDER_CONTENT.md) describes the immediate files. Original ADRs and the M0 packet remain separately preserved alongside extracted definitions.

Use [the decision template](../templates/DECISION.md) for a consequential choice, conflict or material change. Record its actual approval/status and supporting evidence; a proposal or archived choice is not present authority. Routine run progress belongs in run records. Scientific project decisions remain separate from development decisions.
