# Local live observation

Store a working copy at `local/live.md`; do not commit it during an active CWI run. This is an observation, not recovery or acceptance authority.

- Observed at: actual timestamp and timezone.
- Original checkout: path/branch/base and whether any unexpected changes exist.
- Attempt label and raw report paths: actual local references.
- CWI run UUID: confirmed ID, or UNKNOWN with safe discovery procedure.
- Last observed phase/outcome: exact status fields and command time.
- Controller/process ownership: known facts, including uncertain descendants.
- Frozen environment/version: location of recoverable non-secret launch settings.
- Do not do: outstanding constraints, such as no second run or no original-checkout edits.
- Next safe action: one precise inspection/resume/authorization action.

On restart, verify these observations against CWI evidence and Git before acting. Transfer only safe, meaningful summaries into tracked records after the active source-binding constraints have ended.
