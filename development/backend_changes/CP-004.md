## Implementation and source variants

Strict once-per-run means final failures or requested source repairs stop rather than starting another test pass. Every configured command may run at most once; an interrupted uncertain command is never replayed. Source inspection and milestone repair remain available before final execution.

Initial scoped source reviews found no material lifecycle defect. Further actual-CLI probing found that disabling the script host also hid the safe tools from the model-visible tool inventory. Earlier exploratory probes initially used a flattened MCP call name; the decisive regression separately checks actual namespace advertisement and actual namespaced handler results, avoiding that ambiguity. Transient full request capture was removed after safe tool/outcome summaries were retained; no private request payload is part of the adopted patch.

No backward migration or alternate old scheduling path is retained. Baseline APIs/phase and test-baseline state are removed; `BIND_REVIEW` prepares milestone inspection without executing the profile. The controller executes the complete frozen profile only at `FINAL_VALIDATE`. Intermediate Reviewer contexts have no execution results, and milestone criterion evidence must use inspection judgment with no validation IDs. Final acceptance still requires complete passing exact-source evidence, all ordered receipts, full base-to-final review and the existing Git/merge gates. Final repair cannot return to implementation. Test-bootstrap executed-count requirements, source restoration, process supervision, quarantine and immutable result-prefix recovery remain enforced.

Agent inspection uses bounded `list_directory`, paginated UTF-8 `read_file` and literal `search_text` MCP operations, with directory continuation offsets, descriptor-relative no-follow opens and reserved-path/output limits. Only the Writer keeps native patch access. Native read-only image inspection may remain available. Prompts forbid tests, reproductions, interpreters, project imports and alternate execution routes for every role, correction and clarification.
