# Folder contents

Reference documentation: what each part does, and what it does under each condition.

- [OVERVIEW.md](OVERVIEW.md) — How the parts fit together, and where to look for a given symptom.
- [CONTROLLER.md](CONTROLLER.md) — The controller: agent statuses, events, idle and stalled agents, failures, notices, each run.
- [AGENT_ROLES.md](AGENT_ROLES.md) — Primary, subagents, Reviewer and Librarian: what they receive, spawning, results, messages.
- [LIBRARY.md](LIBRARY.md) — The library and the Librarian: shelving, the catalogue, its tools, the end.
- [CONTEXT.md](CONTEXT.md) — Context monitoring and handoffs.
- [FINISHING.md](FINISHING.md) — COMPLETE and STOP, the review, ending and reopening.
- [JOBS.md](JOBS.md) — Jobs: starting, files, statuses, what stops them.
- [QUOTA.md](QUOTA.md) — Usage quota: readings, holds, behaviour while held.
- [CONFINEMENT.md](CONFINEMENT.md) — The bwrap boundary of sessions and jobs, and its consequences.
- [DRIVERS.md](DRIVERS.md) — The CLI sessions from the shared package agent_toolkit: what research_pipeline asks for, discovery switches, setup check.
- [TOOLS.md](TOOLS.md) — The agents' MCP tools, the channel, and every refusal.
- [PROJECT_FOLDER.md](PROJECT_FOLDER.md) — Layout, ownership, layout check, the human's files, git commits.
- [OPERATIONS.md](OPERATIONS.md) — Launching, controls, editing files, logs and troubleshooting.
- [SETUP.md](SETUP.md) — Setting a folder up on the web app's setup page: readiness, material, objectives, the setup assistant.
- [WRITER.md](WRITER.md) — The Writer: the reports for the human, when they are written, the checker's rounds, the page.
- [STATS.md](STATS.md) — Statistics of a run: what is read, how tool calls become file accesses, the Stats view and `stats`.
- [WEB.md](WEB.md) — The web app: setup page, the agent graph, messages and tool calls, single-agent controls.
- [images](images) — Images shown in the README.
